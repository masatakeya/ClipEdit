# ClipEdit

スマートフォンブラウザでの利用に特化した、シンプルで強力なクリップボードテキストエディタです。
他のアプリからコピーしたテキストを一時的に編集・整形して、再びコピーするために設計されています。

## 特徴

- **📋 クリップボード連携**: ボタン一つでペースト・コピーが可能。
- **📱 モバイルファースト**: スマホでの操作性を重視したUI。
- **💾 自動保存**: 入力内容は自動的に保存され、ブラウザを閉じても消えません。
- **↩️ 編集支援**: Undo/Redo、全削除、全選択機能を完備。
- **🕘 クリップボード履歴**: 過去にペースト・コピーしたテキストを最大20件保存し、一覧から選んで復元可能。
- **🔍 検索・置換**: 高度な検索・置換機能を搭載（正規表現対応準備中）。
- **📊 統計情報**: 文字数・行数をリアルタイムで表示。
- **🔒 プライバシー重視**: データはすべてブラウザ内に保存され、外部サーバーには送信されません。

## 使い方

1. **ペースト**: 「貼付け」ボタンを押すと、クリップボードの内容がエディタに貼り付けられます。
2. **編集**: テキストエリアでテキストを自由に編集します。
3. **コピー**: 「コピー」ボタンを押すと、編集した内容がクリップボードにコピーされます。

## クリップボード履歴

「履歴」ボタンから、過去のテキストを最大20件まで一覧で確認できます。項目をタップするとエディタに復元され、右端の「×」で個別に削除できます。

### 保存されるタイミング

履歴は次の3つの操作で保存されます。自動保存（入力中の内容の保持）とは別の仕組みです。

| 操作 | 保存される内容 |
| --- | --- |
| 「貼付け」ボタンを押す | クリップボードから読み込んだテキスト |
| エディタ内で直接ペーストする（⌘V・右クリックなど） | 貼り付けたテキストのみ（エディタ全文ではありません） |
| 「コピー」ボタンを押す | エディタの全文 |

### 重複を抑える仕組み

編集しながら何度もコピーすると、ほぼ同じ内容が履歴に並んでしまいます。これを防ぐため、次の2つの条件で保存を抑制しています。

- **同じテキストは1件にまとめる**: すでに履歴にある内容と完全に一致する場合、新しく追加せず先頭へ移動して時刻だけを更新します。
- **編集途中のテキストは上書きする**: 直前の履歴から**30秒以内**、かつ内容が**80%以上**一致する場合は、編集途中とみなして上書きします。文末への加筆だけでなく文中の修正も検出します。ただし**40文字未満**の短いテキストは、別の内容として扱うため対象外です。

しきい値は `js/constants.js` の以下の定数で調整できます。

| 定数 | 既定値 | 意味 |
| --- | --- | --- |
| `MAX_CLIPBOARD_HISTORY` | `20` | 履歴の保存件数の上限 |
| `HISTORY_MERGE_WINDOW_MS` | `30000` | 編集途中とみなす時間（ミリ秒） |
| `HISTORY_MERGE_SIMILARITY` | `0.8` | 編集途中とみなす類似度（0〜1） |
| `HISTORY_MERGE_MIN_LENGTH` | `40` | 上書き対象とする最小文字数 |

なお、履歴は空白のみのテキストを保存しません。保存先はブラウザのLocalStorage（キー: `clipedit_clipboard_history`）で、外部には送信されません。
